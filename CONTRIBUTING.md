# Contributing to Lemon Clean CRM

This is Lemon Clean's modified fork of Crewtavo. Use feature branches and reviewable pull
requests. Read AGENTS.md before working. Use fictional data only, report tests honestly,
and never deploy production or connect live accounts without the owner's explicit request.
Upstream's authorship, automatic PR-closing and GitLab mirroring policies are restricted to
the upstream repository by this fork's workflows. Retain original licence and attribution.

## Original upstream contribution policy (for jviars/crewtavo)

Crewtavo doesn't accept contributions. Pull requests are closed automatically without review, and
code posted in issues or anywhere else isn't copied in.

You're free to change Crewtavo for yourself under its [license](LICENSE) (AGPL-3.0, with the
additional terms in [NOTICE](NOTICE)). If you run a changed version for other people, offer them
its source code, and don't call it Crewtavo.

## Reporting bugs and security issues

Bugs and ideas: [open an issue](https://github.com/jviars/crewtavo/issues/new/choose). Reports are
read, but there's no promise of support or a reply.
Questions: [ask in Discussions](https://github.com/jviars/crewtavo/discussions/categories/q-a),
where anyone can answer.
Security problems: please don't open a public issue; see [SECURITY.md](SECURITY.md).
